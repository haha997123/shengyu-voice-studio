# 声屿

**仅供个人娱乐，严禁商用。**

Windows 本地配音软件。支持文字配音、声音模仿、试听和音频导出。

## 下载安装

**[点击下载安装助手（Windows 64 位）](https://github.com/haha997123/shengyu-voice-studio/releases/download/v1.4.1/Install-Shengyu.exe)**

1. 点击上面的链接，下载 **Install-Shengyu.exe**。也可查看 [完整下载页](https://github.com/haha997123/shengyu-voice-studio/releases/tag/v1.4.1)。
2. 双击安装程序，使用默认位置或选择其他安装位置，点击“开始安装”。
3. 安装助手会自动下载资源、检查完整性并完成安装。完成后可打开软件，以后从桌面“声屿”快捷方式启动。

无需另装 Python、解压软件或手动合并数据。自动生成的 `Source code (zip)` 不是安装包。下载页中的 `ShengyuData.*` 是安装助手读取的资源，一般不用手动下载。

首次安装需要联网下载约 4.73GB 资源。完整下载的资源会缓存，取消后可重新运行安装程序继续使用已完成的资源。缓存位置需要约 5GB 空间，安装位置建议预留至少 8GB；两者在同一磁盘时建议至少预留 13GB。

适用于 Windows 10/11 64 位 Intel/AMD 电脑，建议 16GB 内存。已有安装目录不会被覆盖，请选择其他位置。

## 功能

- 曼波、派蒙、晓辰：本地配音。
- 声音模仿：使用自己的样音在本地生成。
- 晓晓、云希等在线音色：使用时需要联网。
- 支持导入 TXT、清空文字、试听和导出音频。

本版本保留原完整版的全部模型、运行环境和功能。下载资源拆分只改变传输形式。
