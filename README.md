# 声屿

Windows 本地配音软件的私有备份与下载仓库。

本仓库保持 **Private**。只有仓库所有者及获授权的账号可以查看和下载；朋友需要使用自己的 GitHub 账号接受仓库邀请。仓库链接不等于公开下载链接。

## 下载安装

1. 打开本仓库的 **Releases**，选择 `v1.4.1`。
2. 将以下 7 个文件全部下载到电脑上的同一个新文件夹，保留文件名：
   - `Install-Shengyu.exe`
   - `ShengyuData.001`
   - `ShengyuData.002`
   - `ShengyuData.003`
   - `ShengyuData.004`
   - `ShengyuData.005`
   - `README-Install.txt`
3. 双击 `Install-Shengyu.exe`，使用默认位置或选择其他安装位置，点击“开始安装”。
4. 安装完成后点击“打开软件”，以后可以从桌面“声屿”快捷方式启动。

不要下载 Releases 自动生成的 `Source code (zip)` 来安装，也不要分别打开数据文件。安装助手会自动读取、校验并解压 5 份数据，不需要手动合并、另装 Python 或解压软件。已有“声屿”文件夹不会被覆盖，请选择其他安装位置。

适用于 Windows 10/11 64 位 Intel/AMD 电脑。建议 16GB 内存，安装位置至少预留 8GB 空间。

## 版本内容

`v1.4.1` 保留原完整版的模型与运行环境。分卷只改变传输形式，不减少原版功能。

- 曼波、派蒙、晓辰：本地配音。
- 声音模仿：使用自备样音在本地生成。
- 晓晓、云希等在线音色：使用时需要联网。
- 支持导入 TXT、清空文字、试听和导出音频。

## 来源与使用范围

软件包含第三方代码、模型和参考素材，各自许可适用。请保留软件包内的来源及许可文件。

本仓库的私有设置不代表已经获得第三方角色音色、参考录音或真人声音的额外授权。请勿将本备份视为对这些内容的再分发、商业使用或声音克隆授权。上传自己的样音前，请确认拥有相应使用权限。
